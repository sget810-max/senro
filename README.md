# senro

マインクラフト統合版用アドオン「汽車」(Java版のかまど付きトロッコ相当)。

## 入れ方 (Android)
1. GitHub で `dist/senro.mcaddon` を開き、「Download」(ダウンロード) を押す
2. ダウンロードしたファイルをタップ → マインクラフトで開く → 自動で取り込まれる
3. ワールド設定 → 「ビヘイビアーパック」で **Senro 汽車 BP** を有効化 (リソースパックも自動で付く)

## 遊び方
- **汽車** をレールに置く(レシピ: かまど + トロッコ)
- **燃料**: 汽車に乗ってインベントリを開き、汽車の欄に石炭/木炭を入れる。石炭を持って汽車をタップしても入る(1個 = 3分)
- **運転**: **運転レバー**(レシピ: レバー + 鉄インゴット)を乗った状態で使う、または汽車をタップ → メニューで「火を入れる」
  - 乗ってスティックを前に倒すと煙突の方へ、後ろに倒すと逆へ走り出す
  - 走り出したら、石炭がある限りパワードレールの上のように全速で走り続ける(惰性で止まらない)
  - 走っている向きと逆に倒すとブレーキ、止まったらそのまま逆向きに走り出す
  - 同じ編成なら、汽車以外の車両に乗っていても運転できる(前 = 汽車の煙突の方)。運転レバーもどの車両で使ってもよい
  - 「火を消して停車」でブレーキをかけて止まる。石炭が切れたときだけ惰性で止まる
- パワードレールなしで走り、最高速度は通常トロッコの 1.5 倍
- **補助機関車**(レシピ: トロッコ + かまど + 鉄ブロック)を同じ編成に入れると、最高速度が通常トロッコの 2 倍になる
  - 燃料は不要。単独では走らない(汽車と同じ編成にいるときだけ働く)
- 速度を上げるため、バニラのトロッコ(全種類)の定義を上書きしている。汽車の編成に入っていないトロッコは今まで通りの速さ

## 連結
- **連結器**(レシピ: 鎖 + 鉄インゴット)を持って、車両を1台目→2台目の順にタップすると連結
  - 1台目を選ぶと、車両から手元まで銀色の紐が伸びる。何もない所で使うとやめる
  - つながっている2台を選び直すと切り離し。スニークしながらタップでその車両の連結を全部外す
- 汽車とバニラのトロッコ全種類がつながる。前後1台ずつ、先頭の汽車を含めて最大8両
- バニラのトロッコをつないでいても、編成全体が汽車と同じ速さで走る

## 開発
`python3 tools/build.py` でモデル・テクスチャを生成し、`dist/senro.mcaddon` を作り直す。
