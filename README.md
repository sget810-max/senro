# senro

マインクラフト統合版用アドオン「汽車」(Java版のかまど付きトロッコ相当)。

## 入れ方 (Android)
1. GitHub で `dist/senro.mcaddon` を開き、「Download」(ダウンロード) を押す
2. ダウンロードしたファイルをタップ → マインクラフトで開く → 自動で取り込まれる
3. ワールド設定 → 「ビヘイビアーパック」で **Senro 汽車 BP** を有効化 (リソースパックも自動で付く)

## 遊び方
- **汽車** をレールに置く(レシピ: かまど + トロッコ)
- **燃料**: 汽車に乗ってインベントリを開き、汽車の欄に石炭/木炭を入れる。石炭を持って汽車をタップしても入る(1個 = 3分)
- **運転**: **運転レバー**(レシピ: レバー + 鉄インゴット)を、乗った状態で使う、または汽車をタップ → メニューで「発車」「停車」
  - 発車すると、自分が向いている方向へ走り出す
- パワードレールなしで走り、最高速度は通常トロッコの 1.5 倍
- 燃料切れになると自動で停車

## 開発
`python3 tools/build.py` でモデル・テクスチャを生成し、`dist/senro.mcaddon` を作り直す。
